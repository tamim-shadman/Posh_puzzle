# Security Policy

We actively maintain and provide security patches for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

The Posh Puzzle team takes the security and integrity of our luxury marketplace and user data with paramount importance.

If you believe you have discovered a security vulnerability, **please do not disclose it publicly or file a public GitHub issue**.

### How to Report
Please send an email detailing the vulnerability to:
`security@poshpuzzle.com`

Include:
1. Description of the vulnerability and its potential impact.
2. Step-by-step instructions or proof-of-concept script to reproduce the issue.
3. Affected components, routes, or dependencies.
4. Suggested remediation if known.

### Security Response SLA
- **Initial Acknowledgement:** Within 24 hours of receipt.
- **Triage & Assessment:** Within 48 hours.
- **Fix & Patch Deployment:** Critical vulnerabilities are addressed within 7 business days.

Thank you for responsibly disclosing security vulnerabilities and helping protect our connoisseurs, ateliers, and partners!
